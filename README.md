# Udemy Clone Website

A responsive, feature-rich front-end clone of the Udemy learning platform. Built using **HTML5**, **Tailwind CSS**, and **JavaScript**, this project recreates key Udemy UI elements including responsive mobile navigation, interactive course content accordions, side drawer menus, and dynamic banners.


## 🚀 Features

* **Fully Responsive Design**: Styled with Tailwind CSS to seamlessly adapt across mobile, tablet, and desktop views.
* **Responsive Mobile Header**: Recreates the mobile Udemy navbar complete with hamburger menu, centered branding, search toggle, and cart notification badge.
* **Slide-out Side Navigation**: Interactive mobile drawer navigation with categorized links, arrow indicators, and background backdrop overlay.
* **Interactive Accordion Panels**: Toggleable course sections and lecture content for course curriculum pages.
* **Top Announcement Banner**: Dismissible promotional sale banner with interactive close functionality.


## 🛠️ Tech Stack

* **HTML5**: Semantic markup for page structure and accessibility.
* **Tailwind CSS**: Utility-first CSS framework for rapid UI styling and responsiveness.
* **JavaScript (ES6)**: Vanilla JS for DOM manipulation, interactive menus, and state management.
* **Font Awesome**: Icon library for UI elements (cart, search, menu, stars).
